# Undo System — Rollback Perubahan Kode

> Proyek: Jagres Battle Simulator  
> Diperbarui: 2026-07-04  
> Trigger: user minta undo / rollback / kembalikan perubahan

---

## Ringkasan

Setiap kali user minta undo perubahan, gunakan salah satu dari 3 metode di bawah. Urutan prioritas:

| Prioritas | Metode                    | Kecepatan | Syarat                      |
| --------- | ------------------------- | --------- | --------------------------- |
| 1         | Git local                 | Instant   | Ada commit sebelumnya       |
| 2         | VSCode Local History      | Instant   | IDE Antigravity (selalu ON) |
| 3         | Tanya user                | Manual    | Fallback                    |

---

## Metode 1: Git Local (Commit Lokal)

**Tidak perlu push ke remote.** Commit lokal cukup.

```bash
# Lihat status
git status --short
git log --oneline -5

# Commit snapshot sebelum AI bekerja
git add -A && git commit -m "snapshot pre-AI"

# Undo perubahan uncommitted di file spesifik
git restore <path/file>

# Undo SEMUA perubahan uncommitted
git restore .

# Undo commit terakhir (soft — perubahan tetap ada)
git reset --soft HEAD~1

# Undo commit terakhir (hard — hapus permanen)
git reset --hard HEAD~1
```

**Kapan dipakai:** user belum commit, perlu balik ke commit terakhir.

## Metode 2: VSCode Local History (Otomatis, Tanpa Git)

IDE Antigravity menyimpan snapshot **setiap kali file di-save** di:

```
~/.config/Antigravity IDE/User/History/
```

### Cara temukan history suatu file

```bash
# Cari folder history untuk file tertentu
find ~/.config/Antigravity\ IDE/User/History/ -name "entries.json" -exec grep -l "<nama_file>" {} \;
```

Contoh: file `CameraOcclusionManager.tsx` → folder history: `1a298a2c`

### Cara baca entries.json

```bash
cat ~/.config/Antigravity\ IDE/User/History/<folder_id>/entries.json
```

Format:
```json
{
  "version": 1,
  "resource": "file:///home/yoga/Dokumen/game%20mmorpg/frontend/src/...",
  "entries": [
    { "id": "aBwl.tsx", "timestamp": 1782043770722 },
    { "id": "bvhP.tsx", "source": "undoRedo.source", "timestamp": 1782044333688 }
  ]
}
```

- `id`: nama file di folder history (contoh: `aBwl.tsx`)
- `timestamp`: Unix epoch milliseconds
- `source`: `"undoRedo.source"` berarti dari undo/redo IDE

### Cara restore versi lama

```bash
# Bandingkan ukuran
wc -l ~/.config/Antigravity\ IDE/User/History/<folder_id>/<id>.tsx

# Copy versi lama ke file asli
cp ~/.config/Antigravity\ IDE/User/History/<folder_id>/<id>.tsx <path/file_asli>
```

### Cara user restore sendiri (tanpa AI)

1. `Ctrl+Shift+P` → ketik `Local History: Find Entry to Restore`
2. Pilih file → pilih versi → restore

**Kapan dipakai:** user tidak commit Git, hanya save biasa. Selalu tersedia.

## Metode 3: Tanya User

Kalau kedua metode di atas gagal (misal: file baru, belum pernah di-save, tidak ada di Git), tanya user:

> "File X tidak punya history. Apakah kamu punya backup atau versi sebelumnya?"

---

## Workflow Rekomendasi untuk User

1. **Sebelum minta AI edit besar:** commit lokal dulu  
   `git add -A && git commit -m "snapshot"`

2. **Setelah AI edit, tidak cocok:** bilang "undo perubahan di file X"  
   → AI restore dari Local History atau Git.

3. **Tidak pernah commit, tidak masalah:** Local History tetap merekam.

## Alur Keputusan (Decision Tree)

```
User: "undo perubahan di file X"
    │
    ├─ Ada di Git?
    │   ├─ YES → git restore <file>          ← PRIORITAS 1
    │   └─ NO  → lanjut
    │
    ├─ Ada di Local History?
    │   ├─ YES → temukan folder history → cp versi lama ke file asli  ← PRIORITAS 2
    │   └─ NO  → tanya user                                           ← PRIORITAS 3
    │
    └─ Selesai → konfirmasi ke user
```
